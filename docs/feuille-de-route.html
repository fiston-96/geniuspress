Roadmap

Cinq phases jusqu’à la version 1.0

Les dates sont des estimations pour une petite équipe épaulée par l’IA. Chaque phase se termine quand son critère de fin est atteint, pas à une date fixe.

Faitnovembre 2026

MVP : builder et assistant IA

Terminé

Prouver que le cœur du produit fonctionne de bout en bout.

  • Installation, admin, pages, médiathèque, réglages du site
  • Builder React : glisser-déposer, 7 widgets, aperçu mobile, historique
  • Assistant IA : génération de page, rédaction, traduction, audit SEO et accessibilité
  • 17 tests automatiques, contenu nettoyé et validé côté serveur
Phase 023 nov. 2026

Préparer le dépôt

Terminé
  • Licence AGPL-3.0 et projet d’exception pour les plugins (relecture par un juriste avant la 1.0)
  • README, premier commit, dépôt GitHub fiston-96/geniuspress, sans aucun secret
  • Reste ouvert : le dépôt est public alors qu’il devait être privé, et le nom « GeniusPress » n’est pas encore vérifié (marque, domaine)
Phase 124 nov. 2026

Fondations open source

Presque terminé

Rendre GeniusPress installable par n’importe qui et extensible par des développeurs.

  • Registre de widgets et système de plugins : hooks, routes, fichiers, désactivation automatique en cas d’erreur (fait)
  • Commande geniuspress:make-plugin, plugin d’exemple Citation, guide développeur (fait)
  • Interface traduisible, français et anglais, langue choisie par chaque utilisateur (fait)
  • Installateur depuis zéro, dans le navigateur et en ligne de commande, MySQL ou SQLite (fait)
  • Paquet zip pour hébergement mutualisé, testé de bout en bout (fait)
  • Export et import de site, avec déménagement possible dès l’installation (fait)
  • Image Docker et tests automatiques sur GitHub : écrits, en attente du déblocage de la facturation GitHub pour être validés

Terminé quand la CI GitHub est au vert, Docker compris, et les branches sont fusionnées dans main.

Phase 2janv. 2027 · 3–4 sem.

Un vrai site complet

Prévu

Combler ce qui manque pour qu’une organisation mette son site en ligne sans aide.

  • En-tête, menu et pied de page personnalisables (constructeur de thème)
  • Plugin officiel Formulaire de contact
  • Plugin officiel Paiement et dons : Mobile Money et carte bancaire
  • Traductions de l’interface en swahili et en lingala
  • Nouveaux widgets : icônes, galerie, carrousel, compteurs, onglets, FAQ, carte
  • Modèles de pages prêts à l’emploi (ONG, entreprise, école, église, restaurant)
  • Gestion des utilisateurs dans l’admin, assistant IA en tâche de fond

Terminé quand une ONG crée un site de 5 pages avec menu, formulaire et page de dons en moins d’une heure.

Phase 3févr. 2027 · 2–3 sem.

Hébergement et plateforme

Prévu
  • Déploiement sur VPS : Nginx, HTTPS, sauvegardes quotidiennes hors serveur (à partir de geniuspress:export), supervision
  • Mode plateforme multi-sites (SaaS) avec sous-domaines puis domaines personnalisés
  • Mises à jour en un clic pour les installations autonomes
  • Export en site statique, utilisable sans Internet ou sur réseau local (le mode local avec SQLite fonctionne déjà)
  • Crédits IA GeniusPress pour les sites sans clé API personnelle

Terminé quand un client crée son site sur la plateforme, branche son nom de domaine et reçoit ses sauvegardes automatiquement.

Phase 4début mars 2027

Lancement public 1.0

Prévu
  • Site de documentation complet en français et en anglais
  • Dépôt GitHub public, guide de contribution, politique de sécurité
  • Annonce auprès des communautés tech africaines et des réseaux d’ONG

Terminé quand la 1.0 est publiée et documentée, et que les premiers contributeurs externes ont pu installer le projet seuls.

Fonctionnalités

Ce que fait GeniusPress, et ce qui arrive

Cadre

Décisions prises et questions ouvertes

Décidé

CMS autonome
Pas un plugin WordPress : GeniusPress a son propre cœur, son builder et son assistant IA.
Laravel, React et MySQL
Laravel sert de fondation technique ; tout le CMS est écrit par l’équipe. Fonctionne sur WAMP, sur un VPS et sur un hébergement mutualisé.
Open source
AGPL-3.0 pour le cœur, avec une exception qui laisse les plugins choisir leur licence, y compris commerciale. Kit de plugins et exemples sous MIT.
Claude Opus 5.5 pour l’IA
Clé API personnelle du client, chiffrée en base. Crédits GeniusPress prévus en phase 3.
Les données appartiennent au client
Export complet du site à tout moment, import dans une autre installation : c’est fait.
Quatre façons d’installer
Assistant dans le navigateur, ligne de commande, paquet zip pour hébergement mutualisé, Docker.

À trancher

  1. Compte GitHubRégler la facturation (elle bloque la CI) et choisir si le dépôt reste public avant la 1.0.
  2. Plateforme SaaS, installation par client, ou les deux ?Le code actuel gère un seul site ; le multi-sites ajoute 2 à 4 semaines.
  3. Fournisseurs de paiementAgrégateur Mobile Money et carte selon les pays visés (RDC, Rwanda, Kenya…).
  4. Hébergeur et région du VPSRecommandation : Europe avec Cloudflare devant.
  5. Nom de domaine et marqueVérifier la disponibilité de « GeniusPress » avant le lancement.
  6. Langues de l’interface après le français et l’anglaisSwahili et lingala sont les candidats naturels.
