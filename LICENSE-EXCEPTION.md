# Exception pour les plugins GeniusPress

> **Projet de texte, à faire relire par un juriste avant la version 1.0.**

GeniusPress est distribué sous la licence GNU Affero General Public License, version 3 (fichier `LICENSE`).

En complément, et comme exception supplémentaire au sens de la section 7 de l'AGPL-3.0, les titulaires des droits sur GeniusPress accordent la permission suivante :

1. **Plugin.** Un « plugin » est un ensemble de fichiers distribué séparément de GeniusPress, placé dans le dossier `plugins/` d'une installation, qui interagit avec GeniusPress **uniquement** par son interface publique d'extension : les classes, fonctions, hooks, événements et formats documentés comme publics dans la documentation officielle pour les développeurs.

2. **Permission.** Vous pouvez créer, utiliser, modifier et distribuer un plugin sous la licence de votre choix, y compris une licence propriétaire ou commerciale, sans que les termes de l'AGPL-3.0 s'appliquent au plugin, même si le plugin est exécuté dans le même processus que GeniusPress.

3. **Limites.** Cette exception ne s'applique pas :
   - aux modifications de GeniusPress lui-même, qui restent soumises à l'AGPL-3.0 ;
   - au code de GeniusPress copié dans un plugin ;
   - à un plugin qui contourne l'interface publique pour modifier le fonctionnement interne de GeniusPress.

4. **Retrait.** Si vous modifiez GeniusPress, vous pouvez étendre cette exception à votre version modifiée, mais vous n'y êtes pas obligé. Si vous ne le faites pas, supprimez ce fichier de votre version.

Le kit de développement de plugins et les plugins d'exemple fournis par le projet sont distribués sous licence MIT.
